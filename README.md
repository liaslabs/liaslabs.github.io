# liaslabs.github.io

The root of the liaslabs GitHub Pages site.

- `app-ads.txt`: the AdMob seller line for publisher pub-2380408512555993. AdMob looks for it at the root of the developer website.
- `index.html`: sends visitors at the root on to Blackhole Storm (`/blackhole-storm/`).
- `.nojekyll`: serve the files as they are.
- `blackhole-storm/`: the Blackhole Storm web site (the web game, `privacy.html` that Google Play links to, the
  tester page `test/`, store videos and previews). Built from the game's own repository and copied here on each web
  release; the addresses stay https://liaslabs.github.io/blackhole-storm/… .
